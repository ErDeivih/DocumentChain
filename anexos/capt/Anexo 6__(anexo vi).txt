1 Introducción
Este documento está enfocado a proporcionar una explicación del funcionamiento de
la aplicación a un usuario sin experiencia, de una forma comprensible y sencilla.
El objetivo principal es el de dar un soporte a un nuevo usuario, explicando todas las
interacciones posibles tanto para un usuario cliente como un usuario administrador.
Se explicarán todas las funciones, desde iniciar/cerrar sesión, pedir una receta o ver
estadísticas, hasta funciones más complejas para un administrador como gestionar el
robot, ver la disposición de las bebidas o trabajar con las recetas.
La aplicación está adaptada para distintos tipos de pantallas (es responsiva), por lo
que se contemplará en las imágenes la vista de ordenador principalmente, aunque se
adjuntarán imágenes desde la vista de móvil cuando haya cambios no solo en la
disposición, sino en otros elementos relevantes (cambios en menús, reordenamiento de
elementos, etc).

2.1 Pantalla de pedidos usuario no logueado
La pantalla de inicio para cualquier usuario será la pantalla de pedidos. En este
apartado nos centramos en la vista del usuario no logueado. Aquí un usuario no
logueado podrá hacer 4 cosas:
• Iniciar sesión: el usuario podrá iniciar sesión. Se le redirigirá a la página de
Inicio de sesión.
• Bebidas: consultar las bebidas de una receta
• Pedir: pedir una de las recetas para que sea preparada por el robot.
• Consultar bebidas más pedidas: las medallas situadas en la parte superior
izquierda indican que esas bebidas están en el top 3 de las bebidas más
consumidas por los usuarios.

2.2 Pantalla de inicio de sesión
En esta pantalla un usuario que no haya iniciado sesión dentro del sistema podrá
iniciar sesión si dispone de unas credenciales válidas. Para ello las introducirá en las
casillas de Usuario y Contraseña, pudiendo recordar dichas credenciales hasta que
cierre sesión.
En caso de no disponer de credenciales válidas, el usuario podrá dirigirse a:
•
•
•

Registro: accederá a la pantalla de registro donde podrá registrarse como
cliente en el sistema.
Restablecer contraseña: en caso de olvidar la contraseña, se redirigirá al
usuario a la pantalla para recordar la contraseña.
Pedidos: volverá a la pantalla de inicio para realizar pedidos sin credenciales
válidas (2.1 Pantalla de pedidos usuario no logueado).

En caso de iniciar sesión correctamente, se le redirigirá a la pantalla de inicio (2.1
Pantalla de pedidos usuario no logueado) con una sesión activa. En caso de no poner
correctamente los datos, será notificado.

porcentajes para la receta. Además, las nuevas recetas vienen desactivadas por
defecto, ya que para activarlas se debe de hacer manualmente teniendo las bebidas
dispuestas en el robot.

2.7.3 Pantalla Disposición
En esta pantalla se mostrará de forma visual (según el color asignado a la bebida)
una imagen con las botellas activas en el robot. Esta pantalla pretende ofrecer una vista
similar a la del robot para que esta sea lo más intuitiva posible. Se pueden realizar 3
acciones:
• Asignar una bebida a la disposición de bebidas: se dispone de un
desplegable por cada bebida en la disposición que permite seleccionar la
bebida a colocar en esa posición.
• Eliminar bebida de una posición: en cada posición se dispone de un botón
rojo que permite eliminar la bebida asignada a dicha posición.
• Guardar cambios: en caso de realizar una modificación en la disposición, se
podrán guardar los cambios en el sistema.

2.8.2 Cambio bebidas en dispensadores
Para cambiar una bebida del robot se seguirán los siguientes pasos:
1. Retirar el dispensador: para ello, tirar del tope situado en la parte inferior del
dispensador, y tirar de él hacia el exterior (con cuidado en caso de tener una
botella ya instalada).

Ilustración 55. Retirar dispensadores.

2. Colocar dispensador en la botella: colocar el dispensador con la botella
recta e insertar su goma dentro de la botella lo máximo posible.

Ilustración 56. Colocar dispensador en botella.

32

Anexo VI: Manual de usuario.
3. Colocar dispensador: una vez colocado el dispensador en la botella,
giramos la botella y colocamos el dispensador en el sitio de donde se retiró.
Para ello, levantamos la barra de sujeción del dispensador que sujetará la
botella y empujamos el dispensador en su lugar para volverlo a colocar.

Ilustración 57. Colocar dispensador con botella.
